# /cursor-prompt → Cursor AI 개발 요구사항 프롬프트 작성

Notion/Slack 링크(선택)와 사용자의 개발 방향 설명을 받아,
Cursor AI에게 바로 붙여넣을 수 있는 개발 요구사항 프롬프트를 작성한다.

## 사용법
```
/cursor-prompt [링크(선택)] [개발 방향 설명]
```

예시:
```
/cursor-prompt https://notion.so/... 사용자 만족도 대시보드를 만들고 싶어
/cursor-prompt 어드민 페이지에 CSV 내보내기 버튼 추가하고 싶어
```

## 실행 순서

1. **링크가 있으면 내용 fetch**
   - Notion 링크 → Notion MCP로 페이지 내용 가져오기
   - Slack 링크 → Slack MCP로 스레드 내용 가져오기
   - 링크 없으면 사용자 설명만으로 진행

2. **정보 분석**
   - 기능의 목적과 배경 파악
   - 필요한 기능 목록 추출
   - 기술적 제약이나 힌트가 있으면 추출

3. **프롬프트 작성 후 출력**
   아래 형식으로 구성해서 코드블록 안에 출력 (복사하기 편하도록):

   ```
   ## 배경 / 목적
   왜 만드는지, 어떤 문제를 해결하는지

   ## 기능 요구사항
   - 구현해야 할 기능 1
   - 구현해야 할 기능 2
   - ...

   ## 기술 스택 / 제약 조건
   - 사용 언어, 프레임워크, 라이브러리 (알 수 있는 경우)
   - 지켜야 할 조건 (있는 경우)

   ## 참고 / 힌트
   - 관련 파일이나 컴포넌트 (알 수 있는 경우)
   - 참고할 만한 기존 패턴 (있는 경우)
   ```

## 출력 원칙
- 프롬프트는 Cursor가 바로 작업에 착수할 수 있도록 구체적으로 작성
- 모호한 표현보다 명확한 동사 사용 ("구현", "추가", "수정", "삭제")
- 정보가 부족한 섹션은 생략하거나 "[확인 필요]" 표시
- 추측은 하지 않음 → 불확실한 내용은 사용자에게 확인 후 반영

## 주의사항
- 코드블록으로 감싸서 출력 → 사용자가 바로 복사할 수 있어야 함
- 프롬프트 작성 후 "이 부분을 더 구체화하면 좋을 것 같아요" 식의 보완 제안 1~2개 붙이기
